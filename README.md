# Image-Segmentation-using-Ratio-Cut-and-K-Means-Clustering
Image Segmentation using Ratio-Cut and K-Means Clustering
his project implements Ratio-Cut based clustering for image segmentation and compares it with the classic K-Means clustering technique. Both methods are applied with a fixed number of clusters (3 and 6) on images resized to 64x64 for computational efficiency. The implementation is done from scratch with modular code design and supports batch processing of images from a folder.

📌 Features
✅ Custom implementation of the Ratio-Cut segmentation algorithm.

✅ K-Means clustering using in-built functions for comparison.

✅ Evaluation for both 3 and 6 cluster settings.

✅ Modular code to accept input images from a directory.

✅ Images are resized to 64x64 before processing.
